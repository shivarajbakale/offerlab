# Practice

Blank copies of all 150 NeetCode problems, in the same folders as `neetcode-150/`.
Each file keeps the problem statement, examples, constraints, helper code and tests.
The approach, complexity notes and solution are removed; the function or class
throws `Not implemented` until you fill it in.

```sh
npm run practice                                       # all problems
node --test practice/01-arrays-hashing/*.ts            # one topic
node --test practice/01-arrays-hashing/003-two-sum.ts  # one problem
npm run typecheck
```

Stuck? The worked solution has the same path under `neetcode-150/`.
